# Battleship - 80's Arcade Edition

An 80's theme Battleship game simulation against an AI, built with vanilla HTML/CSS/JavaScript.

## How to Play

1. Open `https://battleship-lint-app-yjkea73y.devinapps.com` in any modern browser
2. **Place your ships** on the grid by clicking cells (press **R** to rotate, or use the buttons)
3. Click **START BATTLE** to begin
4. **Click enemy grid cells** to fire shots — hit all enemy ships to win!

## Features

- Classic Battleship gameplay on 10x10 grids
- 5 ships: Carrier (5), Battleship (4), Cruiser (3), Submarine (3), Destroyer (2)
- AI opponent with hunt/target strategy
- Retro 80's arcade theme with CRT effects, neon glow, and pixel font
- Sound effects via Web Audio API
- Ship placement with rotate, random, and clear options
